Como lançar uma alteração

Clique em qualquer aula do calendário. Você poderá marcar realizada, cancelada, remarcada, definir a nova data e escolher se a aula deve ou não ser cobrada. A alteração fica salva no navegador.

Quando você marca uma aula como crédito, ela deixa de entrar na cobrança atual. O registro permanece no histórico para ser compensado posteriormente.

Se o aluno faltou e você cancelou a aula mas mesmo assim deixou "Cobrar esta aula" marcado, o sistema desconta 1 aula automaticamente na cobrança do mês seguinte — não precisa fazer nada além disso.

Já sabe que o aluno vai treinar menos dias em um mês (ex.: férias)? Use o botão 🏖️ Férias na tela de Cobrança em vez de cancelar aula por aula.

Regras

Os dados ficam armazenados no navegador (localStorage). Use “Exportar backup” regularmente para guardar uma cópia. Para uso em mais de um computador/celular, a próxima evolução deve usar banco de dados e login.

💾 Backup

Os dados ficam salvos automaticamente no navegador, mas o navegador pode ser limpo ou trocado. Baixe um backup (arquivo .json) regularmente — não existe backup automático em segundo plano nesta versão.

🔒 Segurança

Chaves no código✅ Só a chave publicável (anon) fica no navegador — nunca a chave secreta (service_role)
Login✅ Autenticação real via Supabase, com recuperação de senha por e-mail
Políticas RLS⚠️ Confirme no painel do Supabase que as políticas de cada tabela (Alunos, horarios, aulas, cobrancas, pagamentos) liberam acesso para o papel authenticated

Para múltiplos profissionais usando o sistema, cada um deve ver só os próprios dados — hoje o RLS libera por login, não por "dono" dos dados, então revise isso antes de vender o acesso para terceiros.
